# Profile design assets

The approved V40 illustration remains unchanged at `ai-wildland-banner-final.png`.

The name mark and section lettering use outlined glyphs from
[Cormorant Garamond](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond),
by the Cormorant Project Authors. The font is licensed under the
[SIL Open Font License 1.1](licenses/CormorantGaramond-OFL.txt).
The technical profile uses [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope),
also licensed under [SIL OFL 1.1](licenses/Manrope-OFL.txt).
No font download or third-party rendering service is needed when viewing these assets.

`profile-wordmark.svg`, `section-selected.svg`, `section-technical.svg`,
`technical-profile.svg`, `technical-profile-mobile.svg` and `botanical-divider.svg`
adapt their ink colors and panel backgrounds to the embedding page's light or dark color scheme.
Their SVGs contain no JavaScript, external resources or embedded HTML.

The technical profile gives equal space to Agents/LLMs, computer vision and machine learning.
Project numbers connect capabilities to the contribution and implementation links below.
It does not assert proficiency percentages, skill scores or unverified performance metrics.
Project descriptions and links remain real text in the README.
